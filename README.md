## Условие задачи

Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью символа, заданного с клавиатуры.

- `r` — радиус вписанной окружности (вводится пользователем);
- остальные параметры вычисляются: сторона `t = 2r`, радиус описанной окружности `R = r·√2`;
- квадрат расположен «на вершине» (повёрнут на 45°), фигура закрашена полностью.

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. Ввести символ `symbol`, которым будет рисоваться фигура.
3. Ввести радиус `r` (функция `input_r`):
   - если введено не целое число или `r <= 0`, вывести сообщение об ошибке, очистить буфер ввода и повторить ввод.
4. Вычислить радиус описанной окружности: `R` = round(`r` · √2).
5. Для каждой строки `y` от `-R` до `R`:
   1. для каждой клетки `x` от `-R` до `R`:
      - если `|x| + |y| <= R`, вывести `symbol` и пробел (клетка внутри квадрата);
      - иначе вывести два пробела (клетка вне квадрата);
   2. перейти на новую строку.
6. **Конец**

Каждая клетка занимает два знака по ширине, так как символ в консоли примерно вдвое выше, чем шире, и фигура иначе получилась бы вытянутой.

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <stdlib.h>
#include <locale.h>
#include <math.h>

int input_r(void)
{
	int r;

	printf("Введите радиус вписанной окружности r (целое число > 0): ");
	while (scanf("%d", &r) != 1 || r <= 0)
	{
		while (getchar() != '\n');
		printf("Ошибка! Введите целое число больше 0: ");
	}
	return r;
}

int main()
{
	setlocale(LC_ALL, "RUS");

	char symbol;
	int R, x, y;

	printf("Введите символ для рисования: ");
	scanf(" %c", &symbol);

	R = (int)round(input_r() * sqrt(2.0));

	printf("\n");
	for (y = -R; y <= R; y++)
	{
		for (x = -R; x <= R; x++)
		{
			if (abs(x) + abs(y) <= R)
				printf("%c ", symbol);
			else
				printf("  ");
		}
		printf("\n");
	}

	system("pause");
	return 0;
}
```
